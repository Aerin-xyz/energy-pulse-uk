Acceptance volumes by settlement period (BOAV)

Returns the settlement acceptance volumes for the requested settlement period.

Only messages generated for the latest settlement run are returned.

Settlement date parameter must be provided in the exact format yyyy-MM-dd.

GET
/balancing/settlement/acceptance/volumes/all/{bidOffer}/{settlementDate}/{settlementPeriod}
Acceptance volumes by settlement period (BOAV)
