Bid-Offer Acceptances
Market-wide bid-offer acceptances (BOALF)

This endpoint provides the bid-offer acceptance data (BOALF) for multiple requested BMUs or all BMUs. It returns the data valid for a single settlement period.

The settlement period must be specified as a date and settlement period. The date parameter must be provided in the exact format yyyy-MM-dd.

GET
/balancing/acceptances/all
Market-wide bid-offer acceptances (BOALF)
Parameters
Try it out
Name	Description

settlementDate *
string($date)
(query)


The settlement date for the filter.

Example : 2023-01-24



settlementPeriod *
integer($int32)
(query)


The settlement period for the filter. This should be an integer from 1-50 inclusive.

Example : 39



bmUnit
array<string>
(query)


The BM Units to query. Elexon or NGC BMU IDs can be used. If omitted, results for all BM units will be returned.

Example : List [ "T_DINO-2", "HUMR-1" ]



format
string
(query)
