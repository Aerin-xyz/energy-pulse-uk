# Evidence-led content and promotion plan

Maintain distinct intents: homepage=current atlas; power-flow=system categories and sign conventions; mix=definitions and generation composition; interconnectors=transfers; carbon=actual estimates versus forecasts; reports=dated reproducible results. Do not merge URLs on aggregate query data alone.

The new shared disclosure provides immediately crawlable definitions of MW/MWh, GB scope, schedules versus measured output, and a dated report example. It sits below the existing interface and opens on demand. The current report remains the sole historical baseline; no invented all-time records or resurrected archives.

Reviewable promotional brief (not sent):
“Energy Mix's 10–16 November GB generation report retains the official source records and calculation inputs. Elexon transmission-metered generation excluding pumped storage and imports totalled 4,936,620 MWh. Embedded-generation estimates are reported separately; values remain provisional. Read the definitions, dates and reproducible evidence at https://energymix.info/reports/weekly/2026-11-16/.”

Audience: energy researchers, educators and specialist journalists who need an inspectable example, not generic mass outreach. Recipient selection and any outreach require separate approval. No backlink purchases or outbound messages.

Do not automatically change report publication frequency merely for SEO. The validated rolling pipeline remains unchanged; evaluate weekly editorial summaries versus overlapping rolling windows with the owner before changing archive policy.
