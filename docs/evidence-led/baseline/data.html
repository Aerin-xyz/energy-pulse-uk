UK Electricity Data Sources

EnergyMix.info combines public electricity and carbon-intensity data sources to explain Britain’s live power mix in plain English.

This page sets out what each source is used for, why figures can differ between dashboards, and where the important limitations are.

Key sources include Elexon BMRS and FUELINST for live generation, NESO data sources including historic GB generation mix context, the Carbon Intensity API for GB and regional carbon-intensity estimates and forecasts, Sheffield Solar PV Live for embedded solar estimates, and ENTSO-E or BMRS-derived fallbacks for interconnector context.

Known limitations: datasets differ in coverage, embedded generation can be estimated, interconnector carbon impact depends on neighbouring systems, storage conventions vary, and upstream data can lag or be revised.
